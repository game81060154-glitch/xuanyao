# 玄曜 Web 版 1.0

玄曜是一個以手機使用為優先的個人 AI 助手介面。

## 目前版本

- 手機優先的對話介面
- 玄曜核心狀態面板
- 快速任務按鈕
- 本機對話保存（localStorage）
- 離線 Demo 模式：沒有後端時也能直接操作
- 為後續 AI API、工具、資料庫與 PWA 安裝預留結構
- 不把任何 API 金鑰寫入 GitHub

## 啟動

直接開啟 `index.html` 即可使用目前 Demo。

若之後加入後端，可讓前端向 `/api/chat` 發送：

```json
{ "message": "使用者訊息", "history": [] }
```

後端再把請求轉送到實際 AI 服務，避免把秘密金鑰放在手機瀏覽器或 GitHub。

## 目標架構

1. 玄曜核心：對話、記憶、任務編排
2. 工具層：搜尋、檔案、程式、資料處理
3. 資料層：使用者資料與專案資料
4. 安全層：權限、秘密資訊、錯誤處理
5. 手機層：PWA / 可安裝 Web App
6. 後續再視需要包裝成 Android APK

## 原則

- 重要外部操作先確認
- API 金鑰與秘密資訊不進 Git
- 功能模組化，方便持續升級
- 小型功能自動化，大型不可逆操作保留確認
