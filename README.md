# 玄曜 Web 版 1.43

玄曜是一個以手機使用為優先的個人 AI 工作中樞，採「本機優先、後端可插拔、重要外部操作需確認」的架構。

## 目前已完成

- 手機優先的對話介面
- 玄曜核心狀態面板與快速任務
- 本機對話保存（localStorage）
- 無後端時的 Demo 降級模式
- PWA manifest、Service Worker 與可安裝圖示
- GitHub Actions + GitHub Pages 自動部署工作流
- 預留 `/api/chat` 真正 AI 後端介面
- API 金鑰不放入前端或 GitHub
- `/api/health` 提供後端連線、版本與自我修改環境診斷
- 自我修改採安全分支＋驗證＋生命週期閘門，不直接覆寫 main

## 使用方式

直接開啟網站即可使用本機 Demo；接上後端後，前端會向 `/api/chat` 發送：

```json
{ "message": "使用者訊息", "history": [] }
```

後端負責連接真正的 AI 服務，秘密金鑰只應存在後端環境變數。

## 目前架構狀態

- 前端可在無後端時以本機 Demo 運作
- 若部署到同一個 Vercel 專案，前端會自動檢查 `/api/health`
- 若使用 GitHub Pages，靜態功能仍可用；真正 AI 與自我修改後端需另行提供 API Gateway
- `GITHUB_TOKEN` 只允許存在伺服器環境變數，不會送到前端
