# 玄曜 Web 版 1.17

## 本次核心升級

1.16 已建立「研究問題規劃」，1.17 補上「研究證據生命週期」。

資料流現在為：

感知 → 自主判斷 → 發現未知 → 研究規劃 → 查證任務 → 證據紀錄 → 後續重新判斷

## 研究證據資料

前端新增 `xuanyao.research.v1`，每筆紀錄包含：

- question：要查證的問題
- source：來源標記
- summary：證據摘要
- confidence：信心程度
- status：planned / pending / verified 等狀態
- verifiedAt：完成驗證時間
- createdAt / updatedAt

## 安全原則

- 研究規劃本身屬低風險，可由玄曜自主建立。
- 未取得證據前，不得把方案標示為已驗證。
- 外部搜尋、外部帳號、付款、發布及不可逆操作仍受確認閘門限制。
- 研究紀錄納入完整 JSON 匯出與匯入。

## 下一個自然階段

1. 接入真正的外部搜尋/研究來源。
2. 將來源與證據寫入 research record。
3. 驗證後重新評估原方案的 known / confidence。
4. 若證據不足，自動產生下一個最小查證問題。
5. 完成目標後進行「目標滿足度檢查」，必要時自動建立下一步。
