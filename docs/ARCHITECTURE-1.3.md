# 玄曜 1.3 架構

玄曜從聊天頁面逐步升級為手機優先、可持續工作的 AI 中樞。

## 核心層
1. UI：手機優先操作介面。
2. Local Memory：可查看、搜尋、匯出、匯入的本機記憶。
3. Task Engine：任務建立、狀態、完成與刪除。
4. AI Gateway：前端只呼叫 /api/chat，不在瀏覽器暴露模型金鑰。
5. Tool Layer：統一接入搜尋、檔案、產出與外部工具。
6. Automation：後續加入排程與條件觸發。

## 安全
API 金鑰只放後端環境變數或安全密鑰；付費、權限、不可逆及重要外部操作先確認。

## 下一階段
真正 /api/chat 後端、記憶管理、任務優先級、工具呼叫統一介面。
