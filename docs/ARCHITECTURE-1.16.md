# 玄曜 Web 版 1.16

## 研究／查證核心

1. 玄曜可根據目前目標、記憶、任務與未知方案，自主列出真正需要查證的問題。
2. 每個研究項目包含：
   - question：要查什麼
   - purpose：為什麼查
   - priority：優先級
3. 研究項目會轉成可追蹤的本機查證任務。
4. 「需要研究」與「已完成研究」嚴格分開，避免把推測當成事實。
5. 外部研究工具尚未被無條件授權時，不會自動執行外部操作。

## 新閉環

**感知 → 判斷 → 發現未知 → 研究規劃 → 查證任務 → 取得證據 → 更新判斷**

這是玄曜從自主任務管理走向自主研究代理的基礎。

## 安全

研究規劃本身是本機低風險行為；實際使用外部帳號、服務或可能產生外部影響的工具，仍需經權限閘門處理。
