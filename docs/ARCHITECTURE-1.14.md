# 玄曜 Web 版 1.14

## 核心升級

1. **自主判斷**
   - 從使用者目標推導實際需求與限制。
   - 提供 assessment、options、decision。
   - 不把未知資訊冒充成已驗證事實。

2. **未知方案探索**
   - 可提出尚未驗證但合理的替代路徑。
   - 方案標示已知/未驗證與風險。
   - 需要實際查證時，再進入外部研究或工具流程。

3. **風險式決策**
   - 本機低風險工作可自主推進。
   - 外部帳號、付款、刪除、公開發布、不可逆或重大資料變更必須確認。

4. **本機狀態感知**
   - 前端會將少量相關記憶、目前任務與待確認操作送給 AI 後端。
   - AI 因此可以根據玄曜目前狀態，而不是只根據當前一句話判斷。
   - 僅傳送必要摘要，不直接暴露全部本機資料。

5. **判斷可追蹤**
   - 自主判斷會保存於 `xuanyao.decisions.v1`。
   - 使用者可以在介面查看最近判斷。
   - 執行紀錄與工具結果仍保留。

## 目前閉環

目標 → 狀態感知 → 判斷 → 方案探索 → 風險判斷 → 決策 → 任務 → 工具 → 驗證 → 紀錄。

## 安全原則

- 低風險事項自主推進。
- 未知事項標示未知。
- 高風險事項保留使用者決策權。
- API 金鑰只放後端環境變數。
- 本機資料可匯出與還原。
