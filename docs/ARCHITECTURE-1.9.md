# 玄曜 Web 版 1.9

## 目標

把玄曜從「會提出工具需求」推進到「工具可以實際執行並回傳結果」。

## 1.9 已完成

- Responses API function calling
- 本機安全工具：儲存記憶、建立任務
- 工具呼叫循環：模型提出工具呼叫 → 後端驗證 → 工具結果回傳模型
- 前端接收工具結果並執行本機操作
- 工具結果去重，避免重複建立相同操作
- 執行紀錄保留在本機
- 匯出備份包含 messages、tasks、memories、approvals、activities
- 外部、付費、帳號、刪除、不可逆及重要操作仍走確認閘門
- Responses API 設為 store=false，避免玄曜主動要求保存遠端 response

## 執行邊界

本機安全工具可以自動執行。

外部工具目前仍只建立待確認提案；確認流程會留下紀錄，但尚未直接呼叫第三方服務。

## 下一階段

1. 工具結果驗證與錯誤復原
2. 任務優先級、依賴關係與完成判定
3. 記憶搜尋、相關性排序與去重
4. 經確認後的外部工具真正執行
5. 通知與長流程工作流
6. 更完整的手機離線體驗
