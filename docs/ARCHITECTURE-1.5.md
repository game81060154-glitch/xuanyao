# 玄曜 Web 版 1.5

玄曜是手機優先的個人 AI 工作中樞，採「本機優先、後端可插拔、安全確認」架構。

## 1.5 已完成

- 對話與本機歷史
- 本機長期記憶（可保存、清除、匯出、匯入）
- 任務中心
- 任務拆解入口
- 可切換 AI Gateway
- 工具中心：本機安全工具可直接執行；外部、付費、帳號、刪除與不可逆操作保留確認
- PWA / GitHub Pages 前端
- Vercel 相容 AI Gateway

## 工具安全模型

玄曜把工具分成兩類：

1. **本機安全工具**：記憶、任務、資料匯出等，不需要外部權限，可由玄曜自動處理。
2. **外部工具**：涉及帳號、第三方服務、付款、刪除、不可逆或重要外部操作時，只能提出操作計畫並等待使用者確認。

API 金鑰只能放在後端環境變數，不放進手機前端或 GitHub。
