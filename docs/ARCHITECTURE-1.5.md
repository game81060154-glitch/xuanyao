- 外部工具、付費、帳號、刪除、不可逆或重要操作必須經使用者確認

- PWA / GitHub Pages 前端
- Vercel 相容 AI Gateway

## 工具安全模型

玄曜把工具分成兩類：

1. **本機安全工具**：記憶、任務、資料匯出等，可由玄曜自動處理。
2. **外部工具**：先建立待確認項目；使用者確認後才允許進入下一個外部執行階段。

目前 1.8 的「確認」只會改變提案狀態並留下紀錄，尚未自動呼叫第三方服務，避免未授權的外部行動。

API 金鑰只能放在後端環境變數，不放進手機前端或 GitHub。
