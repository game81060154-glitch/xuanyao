# 玄曜 Web 版 1.15

## 本版重點：自主判斷 → 驗證

玄曜現在會把「未驗證方案」轉成可追蹤的本機驗證任務，而不是只把未知資訊顯示給使用者。

### 新閉環

1. 分析目標與目前本機狀態。
2. 提出已知與未知方案。
3. 評估方案風險。
4. 選擇低風險下一步。
5. 對 `known=false` 的方案建立「驗證未知方案」任務。
6. 驗證完成後，再由後續判斷重新評估。
7. 自主判斷、任務、活動與自動化狀態可一起備份與還原。

### 資料安全

- 驗證任務只在本機建立，不會自動對外執行。
- 外部搜尋、帳號、付款、發布、刪除與不可逆操作仍受確認閘門控制。
- 備份包含自主判斷紀錄與自動化狀態。

### 目標

讓玄曜逐步形成：

**感知 → 判斷 → 探索 → 驗證 → 執行 → 驗證結果 → 再判斷**

這是從一般 AI 聊天介面走向個人工作代理核心的重要基礎。
