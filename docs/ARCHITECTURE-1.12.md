# 玄曜 Web 版 1.12

## 核心升級
- 記憶搜尋改為可排序的相關性結果。
- 釘選記憶具有較高優先權。
- 關鍵字命中與完整片語命中會提高排序。
- 任務工作流依前置依賴數量與建立時間排序，優先處理阻塞較少的任務。
- 工具失敗紀錄可保留 action、狀態、詳細原因、嘗試次數與時間。
- 延續 1.11 的驗證與單次安全重試機制。
- 外部、付費、不可逆操作仍需要使用者確認。

## 目前資料閉環
目標 → 規劃 → 任務 → 依賴 → 執行 → 驗證 → 復原 → 診斷 → 紀錄。

## 下一步方向
- 將工作流排序直接整合到任務中心。
- 更精細的記憶類型與權重。
- 使用者可查看工具失敗原因。
- 通知與排程工作流。
- 經確認後的外部工具執行。
